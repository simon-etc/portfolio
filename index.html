Présentation de l'entreprise

La SNCF est l'entreprise ferroviaire publique française, premier réseau ferroviaire d'Europe avec plus de 30 000 km de lignes. Elle assure quotidiennement le transport de millions de voyageurs via ses services TGV, Intercités, TER et Transilien, tout en gérant l'ensemble des infrastructures ferroviaires nationales.

Mise en place Active Directory avec controle d'acces

Projet BTS | Decembre 2024

Contexte

Mise en place d'un environnement Active Directory pour gerer les utilisateurs et appliquer des politiques de securite differenciees selon les profils.

Solutions mises en oeuvre

  • Installation et configuration d'un serveur Windows Server 2022
  • Deploiement du role Active Directory Domain Services (AD DS)
  • Creation de deux comptes utilisateurs avec niveaux d'acces differents
  • Configuration d'un groupe de securite pour faciliter la gestion des droits
  • Mise en place de GPO (Group Policy Objects) pour appliquer des politiques de securite
  • Tests de connexion et verification des restrictions d'acces

Apports pour le systeme d'information

Centralisation de la gestion : Controle unifie des utilisateurs et groupes depuis une console unique.
Securite renforcee : Application automatique des politiques selon les profils, limitation des privileges.
Scalabilite : Infrastructure evolutive facilitant l'ajout de nouveaux utilisateurs et politiques.

Authentification/gestion centralisee et service d'annuaire sous LINUX : LDAP, OpenLDAP et Samba AD

Projet BTS | A venir

Contexte

Mise en place d'une solution d'authentification et de gestion centralisee des utilisateurs sous Linux via un annuaire LDAP, OpenLDAP et Samba Active Directory pour unifier la gestion des identites dans un environnement heterogene.

Solutions mises en oeuvre

  • Installation et configuration d'OpenLDAP sur serveur Linux
  • Structure de l'annuaire (DIT) : OU, CN, groupes et utilisateurs
  • Configuration de PAM et NSS pour l'authentification LDAP
  • Deploiement de Samba en mode Active Directory Domain Controller
  • Integration des clients Linux et Windows dans le domaine Samba AD
  • Gestion des politiques de mot de passe et des ACL
  • Tests d'authentification et de partages de fichiers cross-plateforme

Apports pour le systeme d'information

Centralisation : Annuaire unique pour tous les utilisateurs Linux et Windows.
Interoperabilite : Environnement heterogene unifie grace a Samba AD.
Securite : Politiques de mots de passe centralisees et gestion fine des acces.

LDAP OpenLDAP Samba AD Linux PAM NSS Kerberos
